# Analytics Slash Assistant

A notebook-based analytics assistant that allows users to run data workflows using slash commands instead of writing Python code.

## Features
- CSV upload
- Data profiling
- Data quality checks
- Cleaning
- EDA
- KPI generation
- Root-cause analysis
- Visualization
- Executive summaries
- Final reports

## Interface
Users interact using commands like:

/profile  
/data-quality  
/eda  
/summary  

## Goal
Enable non-technical users to generate insights without coding.
